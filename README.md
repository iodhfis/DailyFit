# Daily Fit · 상황 기반 AI 스타일 매칭 앱

빅데이터과 캡스톤디자인 졸업작품의 **클릭 프로토타입**입니다.
연구 결과(상황별 스타일 선호도, 스타일 간 상관관계)를 바탕으로 설계한 앱 화면을 웹에서 직접 눌러볼 수 있게 만들었습니다.

- 처음부터 체험하기: `index.html`
- 전체 화면 모아보기: `screens.html`

## 체험할 수 있는 흐름

1. 스플래시 → 로그인 → 홈
2. 홈 → 상황 선택 → 로딩 → 추천 결과 3안 (사진을 누르거나 옆으로 밀면 다음 안)
3. 추천 결과 → 저장 / 숨김 / 비슷한 룩
4. 3안을 모두 숨기면 → 추천 없음 → 숨긴 룩 다시 보기
5. 홈 → 음악 선택 → 음악 무드가 반영된 추천 결과
6. 홈 → A vs B 투표 → 투표 완료
7. 룩북 → 룩 상세 → 아이템 정보
8. 마이 → 설정 → 로그아웃 / 회원 탈퇴
9. 회원가입 → 개인정보 동의 → 권한 안내 → 온보딩 평가 → 취향 선택 → 온보딩 완료 → 홈 (신규 사용자는 룩북이 빈 화면으로 나와요)

## GitHub Pages로 올리기

1. 이 폴더의 파일 전부를 저장소 맨 위(루트)에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택하고 Save를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 에서 열립니다.

## 데이터 근거 (화면 반영 내용)

- 캐주얼: 평균 선호도 1위, 11개 상황 중 6개 상황에서 1위 → 첫 추천 기본값 "캐주얼 기본안"
- 상황 11(애인 · 겨울 · 흐림 0°): 페미닌 3.6 / 긱시크 3.5 접전 → A vs B 투표 예시
- 빈티지 ↔ 고프코어 상관 0.66 → 홈 "이런 스타일은 어때요?" 추천
