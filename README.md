# Daily Fit · 상황 기반 AI 스타일 매칭 앱

빅데이터과 캡스톤디자인 졸업작품의 **클릭 프로토타입**입니다.
연구 결과(상황별 스타일 선호도, 스타일 간 상관관계)를 바탕으로 설계한 앱 화면을 웹에서 직접 눌러볼 수 있게 만들었습니다.

- 처음부터 체험하기: `index.html`
- 전체 화면 모아보기: `screens.html` (핵심 / 시작·계정 / 추천 과정 / 룩북·마이·설정 / 선택 상태로 나눠 볼 수 있어요)

## 데모 계정

| 아이디 | 비밀번호 |
|---|---|
| 000 | 000 |

- 로그인 화면 하단에도 표기되어 있어요. 서버 없이 브라우저 안에서만 확인하는 데모용 로그인이에요.
- 회원 탈퇴 비밀번호도 `000`이에요.
- 회원가입은 이메일·비밀번호를 아무렇게나 입력해도 넘어가요.

## 체험할 수 있는 흐름

1. **시작**: 스플래시 → 로그인 → 홈
2. **추천 결과**: 홈의 검정 '데이트' 카드 또는 전체 상황 → 데이트 → 로딩 → 추천 결과 3안
   - 사진을 누르거나 옆으로 밀면 다음 안으로 넘어가요.
   - 1안: 저장 · 숨김 · 비슷한 룩 / 2·3안: 저장 · 숨김
   - 1·2안 숨김 시 다음 안, 3안 숨김 시 '추천 결과 없음' 화면
   - 저장한 룩은 다른 화면에 다녀와도 저장 상태가 유지돼요.
3. **음악 선택**: POP(기본 선택) · 인디 록
   - POP: 무드 설명만 제공 (추천 진입은 인디 록만 가능)
   - 인디 록: 로딩 → 음악 무드가 반영된 추천 결과 3안 (1·2안 숨김 시 다음 안으로, 3안은 마지막 추천이라 숨길 수 없다는 안내)
4. **A vs B 투표**: A 또는 B를 고르고 투표 → 투표 결과
5. **룩북**: 룩 상세 → 아이템 정보 (룩 상세에서 저장 · 비슷한 룩) / 필터: 버튼을 자유롭게 눌러보고 '룩 보기'로 룩북 이동
6. **마이**: 설정 → 로그아웃(→ 로그인) / 회원 탈퇴(→ 스플래시)
7. **온보딩** (카드 5장 → 취향 선택 → 온보딩 완료 → 홈)
   - 비로그인: 회원가입 → 개인정보 동의 → 권한 안내 → 온보딩
   - 로그인: 마이 → 취향 다시 평가하기 → 초기화 → 온보딩
   - 카드마다 싫음 · 보통 · 좋음 중 하나를 고르면 '취향이 반영되었어요!' 안내가 뜨고 다음 카드로 넘어가요.
   - 온보딩을 마치면 룩북은 빈 화면으로 보여요.

## 시안의 범위

- 홈의 상황 카드(출근 · 여행 · 캠퍼스 · 친구 모임)와 상황 시트의 데이트 외 상황은 "시안에서는 데이트 추천만 볼 수 있어요" 안내가 떠요.
- '이런 스타일은 어때요?'는 고프코어 룩 상세(저장 전)로 바로 연결되고, 저장과 아이템 정보까지 볼 수 있어요.
- 비슷한 룩은 데이트 1안에서만 볼 수 있고, 그중 첫 번째 룩만 룩 상세 → 아이템 정보로 들어갈 수 있어요.
- 룩북에서는 소프트 캐주얼 룩만 룩 상세로 들어갈 수 있어요.
- 고프코어 · 인디 록 추천 화면에서는 룩북으로 이동하지 않고 안내 문구가 떠요.
- 아이템 정보의 구매처는 실제 링크가 연결되어 있지 않아요.
- 준비되지 않은 화면을 누르면 상황에 맞는 안내 문구가 떠요.

## GitHub Pages로 올리기

GitHub 웹 업로드는 한 번에 100개까지라 세 번에 나눠 올려요.

1. 저장소 첫 화면에서 **Add file → Upload files**로 `assets` 폴더를 뺀 나머지 파일을 올리고 Commit
2. 저장소의 `assets` 폴더로 들어가서 **Add file → Upload files**로 `thumbs` 폴더를 올리고 Commit
3. 다시 `assets` 폴더 안에서 `img` 폴더, `font` 폴더, `app.js`를 올리고 Commit
4. 처음 한 번만: **Settings → Pages**에서 Branch `main` / `(root)` → Save
5. Actions 탭의 배포가 초록 체크가 되면 `https://<아이디>.github.io/<저장소 이름>/`에서 열려요.

- 상황 11(애인 · 겨울 · 흐림 0°): 페미닌 3.6 / 긱시크 3.5 접전 → A vs B 투표 예시
- 빈티지 ↔ 고프코어 상관 0.66 → 홈 "이런 스타일은 어때요?" 추천
